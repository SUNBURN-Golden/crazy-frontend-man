# crazy-frontend-man

CrazyFrontendManBOT의 작업 원본 저장소예요. 사이트 프론트엔드를 Apple 수준 UX/UI로 다듬어요.

## 구성
- `skills/` 프론트엔드 감사·검증·토큰·교훈 스킬
- `instagram/` 계정별 인스타그램 에셋과 생성 스크립트(`gen.py`)
- `brands/` 사이트별 색과 공통 디자인 규칙
